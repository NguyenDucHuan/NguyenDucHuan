## Selected projects

> These projects best represent my backend development experience, architecture knowledge, and ability to build business-oriented software.

### [AptCare](https://github.com/NguyenDucHuan/AptCare_BE)

**Apartment management platform | .NET 8 · PostgreSQL · Redis · RabbitMQ · SignalR**

A backend system for managing apartments, residents, services, maintenance requests, payments, and notifications.

- Layered architecture with API, Service, Repository, and Unit Test projects
- JWT authentication, BCrypt password hashing, and Google OAuth
- PayOS payment integration and Excel import/export
- Real-time notifications with SignalR
- Asynchronous messaging with RabbitMQ and distributed caching with Redis
- AWS S3 and Cloudinary integration for file and image storage

### [TascoSystem](https://github.com/NguyenDucHuan/TascoSystem)

**Task and project management platform | .NET 8 · Microservices · Docker · RabbitMQ**

A microservices-based backend designed to manage users, projects, tasks, workflows, and notifications.

- API Gateway with JWT authentication and service routing
- Separate services for authentication, projects, tasks, orchestration, and notifications
- Asynchronous communication with RabbitMQ
- SQL Server and PostgreSQL used according to service requirements
- Docker Compose setup for local multi-service development
- Dedicated notification worker with email templates and priority handling

### [DiamondShop MVC](https://github.com/NguyenDucHuan/DiamondShop_MVC)

**E-commerce management system | ASP.NET MVC 5 · SQL Server · Entity Framework**

A full web application for diamond product management, shopping cart workflows, orders, customers, inventory, and administration.

- Layered architecture with presentation, service, repository, DAO, and business object layers
- Product search, filtering, shopping cart, checkout, and order history
- Admin dashboard for products, customers, orders, inventory, and reports
- Server-rendered MVC application using Razor, Bootstrap, and jQuery

### [MilkTea Management POS](https://github.com/NguyenDucHuan/MilkTeaManagementPos)

**Windows point-of-sale application | .NET 6 · WPF · SQL Server · EF Core**

A desktop POS application supporting daily operations for milk tea shops.

- Product, customer, order, invoice, and account management
- Multi-layer architecture with UI, BLL, and DAL projects
- Entity Framework Core persistence with SQL Server
- Desktop application development with WPF
