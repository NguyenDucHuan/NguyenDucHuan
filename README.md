<h2 align="center">🚀 Featured Projects</h2>

### 🏢 [AptCare](https://github.com/NguyenDucHuan/AptCare_BE)

> A comprehensive apartment management backend for managing apartments, residents, services, maintenance requests, payments, and notifications.

- **Role:** Backend Developer
- **Architecture:** Layered architecture with API, Service, Repository, and Unit Test projects
- **Key features:**
  - User authentication and authorization with JWT, BCrypt, and Google OAuth
  - Apartment, resident, service request, and maintenance management
  - Payment processing with PayOS
  - Real-time notifications using SignalR
  - Email notifications and asynchronous messaging with RabbitMQ
  - Distributed caching with Redis
  - File and image storage using AWS S3 and Cloudinary
  - Excel import/export functionality
- **Tech stack:** .NET 8, ASP.NET Core Web API, PostgreSQL, Entity Framework Core, Redis, RabbitMQ, SignalR, AWS S3, Cloudinary, PayOS, xUnit

### 🧋 [MilkTeaPOS](https://github.com/NguyenDucHuan/MilkTeaPos_BE_v1)

> A point-of-sale backend system designed to support daily operations for milk tea shops, from product management to order processing and payments.

- **Role:** Backend Developer
- **Architecture:** Layered architecture with API, DAL, and Domain projects
- **Key features:**
  - Role-based access control for staff and managers
  - Product, category, size, topping, and combo management
  - Real-time order creation, tracking, and order history
  - Multiple payment methods with PayOS online payment integration
  - Voucher management with amount- and percentage-based discounts
  - Product image management using Cloudinary
  - JWT authentication and BCrypt password hashing
- **Tech stack:** .NET 8, ASP.NET Core Web API, MySQL, Entity Framework Core, JWT, Docker, Cloudinary, PayOS, AutoMapper, Swagger
